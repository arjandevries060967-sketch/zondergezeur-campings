# Pre-live checklist

## Content

- [ ] Exact domein bevestigen: `dehane.zondergezeur.nl` of anders.
- [ ] Officiele toestemming voor gebruik van De Hane-foto's.
- [ ] Contactgegevens definitief invullen.
- [ ] Tarieven definitief controleren.
- [ ] Het Haantje: startdatum, prijs, huisdieren en voorzieningen controleren.
- [ ] SVR-vermelding en EU/ELFPO-vermelding controleren.
- [ ] Demo-disclaimer verwijderen of aanpassen zodra er toestemming is.

## Techniek

- [ ] `npm run lint` groen.
- [ ] `npm run build` groen.
- [ ] GitHub repository gekoppeld.
- [ ] Vercel project gekoppeld aan GitHub.
- [ ] Vercel Production env-vars ingesteld.
- [ ] Resend domein geverifieerd.
- [ ] Beschikbaarheidsformulier getest.
- [ ] DNS en HTTPS actief.

## Mail

- [ ] `RESEND_API_KEY` ingesteld.
- [ ] `RESEND_FROM` gebruikt geverifieerd domein.
- [ ] `RESEND_TO` wijst naar testontvanger of eigenaar.
- [ ] Reply-to van aanvraag staat op e-mailadres bezoeker.
- [ ] Geen databaseopslag in fase 1.
