# Zondergezeur campings

Monorepo voor campingwebsites binnen het concept zondergezeur.nl.

## Sites

- `dehane/` - demo voor Minicamping De Hane

## Vercel

Maak per camping een apart Vercel-project en stel de root directory in op de map van die camping.

Voor De Hane:

- Projectnaam: `dehane`
- Root directory: `dehane`
- Domein: `dehane.zondergezeur.nl`

## Nieuwe camping toevoegen

Maak later een nieuwe map naast `dehane`, bijvoorbeeld:

```text
campingdeboshut/
```

Daarna kan die eigen content, foto's en Vercel-project krijgen.
